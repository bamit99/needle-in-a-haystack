## Gotchas (already ruled, do not redo)

- `node --test test/` breaks on this box (dir arg read as module). Use bare `node --test` or a file path.
- Mock http servers in tests must consume the request body (`req.on('data', ...)`) or `'end'` never fires and the adapter times out.
- `liveMetrics` lives in `public/app.js` (browser can only load `/public`; `src/` is not served).
- UI event order: `runScopedEvents(events, runId)` then `orderEvents(...)` by lane `seq`. Re-runs reset state; the old websocket's close shows a harmless "Event stream closed" warning.
- `concurrency: 1` default; `mode` (`race` / `sequential_lanes`) + `laneConcurrency` recorded in every export.
- Errors stay in item-level denominators; undefined metrics are `null` → `N/A`.
